# Frontend-Backend Integration

## Overview
The frontend communicates with the backend using REST APIs to exchange data securely.

## Integrated Modules
- User Registration
- User Login
- Driver Registration
- Ride Booking
- Live Tracking
- SOS Emergency

## Workflow
1. User submits data.
2. Frontend validates input.
3. Request sent to backend API.
4. Backend processes request.
5. Response displayed on frontend.

## Benefits
- Real-time communication
- Faster response
- Improved user experience
