# Login Page

## Overview
The Login Page allows registered users, drivers, and administrators to securely access the Smart Cab Security Platform.

## Features
- User Login
- Driver Login
- Admin Login
- Forgot Password
- Remember Me option
- Input Validation

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Backend Authentication API

## Workflow
1. User enters email and password.
2. Credentials are validated.
3. Authentication request is sent to the backend.
4. On successful login, the user is redirected to the dashboard.
5. Invalid credentials display an error message.
