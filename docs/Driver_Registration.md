# Driver Registration Page

## Overview
The Driver Registration Page allows new drivers to register and become part of the Smart Cab Security Platform.

## Features
- Personal Information Form
- Driving License Upload
- Vehicle Information
- Contact Details
- Password Creation
- Form Validation

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Backend Registration API

## Workflow
1. Driver fills in registration details.
2. Documents are uploaded.
3. Data is validated.
4. Registration request is sent to the backend.
5. Driver account is created after successful verification.
