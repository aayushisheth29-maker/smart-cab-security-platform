# Ride Booking Page

## Overview
The Ride Booking Page enables passengers to book rides quickly and securely.

## Features
- Pickup Location
- Destination
- Cab Selection
- Fare Estimation
- Confirm Booking
- Booking Status

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Maps API
- Backend Ride Booking API

## Workflow
1. User enters pickup and destination.
2. System calculates estimated fare.
3. Available drivers are displayed.
4. User confirms the booking.
5. Ride request is sent to the driver.
