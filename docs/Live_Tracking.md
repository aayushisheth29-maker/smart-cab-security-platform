# Live Tracking Page

## Overview
The Live Tracking Page allows users to monitor the real-time location of their booked cab.

## Features
- Real-time Driver Location
- Route Display
- Estimated Arrival Time
- Ride Status Updates
- Map Integration

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Maps API
- GPS Tracking

## Workflow
1. Ride is confirmed.
2. Driver location is updated continuously.
3. User can view the route on the map.
4. ETA is displayed until the ride is completed.
