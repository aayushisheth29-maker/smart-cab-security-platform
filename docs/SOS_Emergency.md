# SOS Emergency Page

## Overview
The SOS Emergency feature enhances passenger safety by allowing immediate emergency assistance during a ride.

## Features
- One-Tap SOS Button
- Live Location Sharing
- Emergency Contact Alerts
- Driver Information Display
- Emergency Notification

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GPS Services
- Backend Emergency API

## Workflow
1. User presses the SOS button.
2. Current location is captured.
3. Emergency contacts are notified.
4. SOS request is sent to the backend.
5. Emergency assistance is initiated.
